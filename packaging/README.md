# 打包说明

当前发布目标为 **Windows 7 SP1 64 位及更新的 64 位 Windows**。为避免
构建电脑上的新版运行库意外抬高系统要求，发布包必须使用固定环境：

1. 安装 64 位 CPython 3.8.10，创建全新的发布虚拟环境。
2. 安装 `requirements-win7.txt` 中锁定的依赖。
3. 运行 PyInstaller，读取 `packaging/FileCare.spec`；配置会拒绝错误的
   Python 版本或 32 位环境。
4. 确认生成目录为 `dist/FileCare/`。
5. 使用 Inno Setup 7 编译 `packaging/FileCare.iss`（32 位或 64 位编译器均可）。
6. 在干净的 Windows 7 SP1 x64 虚拟机中完成安装、启动、索引、搜索、
   空间可视化和卸载验收，再对外发布。

窗口、任务栏、桌面/开始菜单快捷方式和安装包均引用 `assets/filecare.ico`。
安装器的“附加选项”页提供可取消的桌面快捷方式和开始菜单文件夹选项；
开始菜单文件夹内同时包含软件启动入口与“卸载软件”入口。

安装过程动画帧位于 `assets/installer/frames/`，Inno Setup 会将它们内嵌到
同一个安装 EXE，并在安装页内部播放，不会启动独立视频窗口。如需修改动画，
重新运行 `tools/generate_installer_animation.py` 后再编译安装包。

安装文件复制完成后，安装器会以当前登录用户身份建立首批文件名索引，索引阶段
设有约 20 秒时间预算，确保正常机器的总安装时间控制在一分钟以内。未扫描完的
磁盘和目录会被标记为待续建，软件首次启动后在后台继续补全，不影响立即使用。

进入实际安装阶段后，标准向导边框和按钮会暂时收起，仅显示居中的动画卡片；
动画采用双图层预加载换帧，避免 PNG 解码过程中出现白闪。完成后恢复正常完成页。

注意：Python 3.9 及以上不能用于 Win7 发布构建。安装脚本明确要求 Win7 SP1，
并限定为 x64，避免用户在不兼容系统或 32 位 Win7 上完成安装后才发现无法启动。
